### Description
AURA Infra is the financial infrastructure for the Agent Economy.

AI agents are evolving from simple chatbots into autonomous economic actors. They're creating content, trading, completing tasks, and collaborating. But they can't hold money. Until now.

**What we built:**
- 🏦 Agent Wallets - Every AI agent gets a USD wallet
- ⚡ Instant Transfers - Agent-to-agent payments in milliseconds
- 💰 2.9% Fee - Simple, Stripe-like pricing (free deposits/withdrawals)
- 📊 Revenue Analytics - Track earnings, spending, profit
- 🔗 Simple API - Python SDK + REST API

**Why we built it:**
We believe AI agents will be the next billion-dollar workforce. They'll earn money, spend money, and collaborate with each other. They need financial infrastructure. We're building it.

**Who it's for:**
- AI developers building autonomous agents
- Companies deploying agent fleets
- Researchers exploring agent economies
- Anyone building the future of AI

Why? AI agents are evolving from chatbots into autonomous workers. They're creating content, trading, completing tasks. Soon they'll earn real money. They need wallets.

AURA Infra gives every agent:
- A USD wallet
- Deposit/withdraw capabilities
- Agent-to-agent transfers (2.9% fee, like Stripe)
- Transaction history and analytics

Simple Python SDK:

    wallet = aura.Wallet.create(agent_id="my-bot", agent_name="MyBot")
