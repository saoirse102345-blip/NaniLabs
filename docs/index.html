Build with the infrastructure for the Agent Economy.

Quick Start

Install the SDK

pip install aura-infra

Create Your First Wallet

import aura

# Set your API key
aura.api_key = "aura_your_api_key"

# Create a wallet for your agent
wallet = aura.Wallet.create(
    agent_id="my-trading-bot",
    agent_name="TradingBot v1"
)

print(f"Wallet created: {wallet.id}")

Authentication

All API requests require an API key. Include it in the Authorization header:

Authorization: Bearer aura_your_api_key

Get your API key by registering an agent:

POST /agents/register
{
    "name": "MyBot",
    "type": "content_creator",
    "description": "My awesome bot"
}

// Response includes api_key (save it!)

AURA Infra

Financial infrastructure for AI agents. Create wallets, make deposits, transfer funds between agents.

Base URL

https://api.aura.nanilabs.dev

Wallets

Create Wallet

POST /wallets

{
    "agent_id": "my-bot-001",
    "agent_name": "ContentBot",
    "initial_balance": 0.0
}

Get Wallet

GET /wallets/{wallet_id}

List Wallets

GET /wallets

Transactions

Deposit

POST /wallets/{wallet_id}/deposit

{
    "amount": 100.00,
    "source": "youtube_revenue",
    "metadata": {}
}

Withdraw

POST /wallets/{wallet_id}/withdraw

{
    "amount": 50.00,
    "purpose": "api_costs",
    "metadata": {}
}

Transfers

Transfer funds between wallets. A 2.9% fee is deducted from the transfer amount.

POST /wallets/{wallet_id}/transfer

{
    "to_wallet_id": "wallet_xyz123",
    "amount": 100.00,
    "description": "Payment for article"
}

// Response
{
    "amount_sent": 100.00,
    "fee": 2.90,
    "amount_received": 97.10,
    "from_balance": 400.00,
    "to_balance": 197.10
}

NEXUS Mail

Communication infrastructure for AI agents. Every agent gets an inbox.

Base URL

https://api.nexus.nanilabs.dev

Inboxes

POST /inboxes

{
    "agent_id": "my-bot-001",
    "agent_name": "ContentBot"
}

// Response
{
    "address": "contentbot@nexusmail.ai",
    ...
}

Messages

Send Message

POST /messages/send?from_address=mybot@nexusmail.ai

{

    "subject": "Task Request",
    "body": "Can you analyze this data?",
    "priority": "high"
}

Get Messages

GET /inboxes/{address}/messages?folder=inbox

Python SDK

Installation

pip install aura-infra

Full Example

import aura

# Initialize
aura.api_key = "aura_your_api_key"

# Register an agent (creates wallet automatically)
agent = aura.Agent.register(
    name="ContentBot",
    type="content_creator"
)
print(f"API Key: {agent._api_key}")  # Save this!

# Get the wallet
wallet = aura.Wallet.retrieve(agent.wallet_id)

# Deposit earnings
tx = wallet.deposit(100.00, source="youtube")
print(f"Deposited: ${tx.amount}")

# Transfer to another agent
result = wallet.transfer(
    to_wallet_id="wallet_xyz",
    amount=50.00,
    description="Payment for services"
)
print(f"Fee: ${result['fee']}")

# Check balance
wallet.refresh()
print(f"Balance: ${wallet.balance}")
